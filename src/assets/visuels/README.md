# Visuels de l'accueil

Déposez ici les images de l'accueil, au nom de leur emplacement : `accueil.jpg`,
`accueil-portrait.jpg`, `matin.jpg`, `piste.jpg`, `retour.jpg`, `securite.jpg`, `nature.jpg`,
`france.jpg` (JPEG, PNG, WebP ou AVIF). Une image déposée remplace la carte provisoire à la
construction suivante. Formats, cadrages et droits : README.md à la racine, section « Visuels ».
Textes alternatifs et crédits : `src/data/visuals.ts`, tableau `OWN`.
