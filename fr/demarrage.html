Démarrage

Trois chemins selon ce que vous voulez faire : installer l'app, construire un pack sur votre ordinateur, ou contribuer au code.

Installer l'app

L'app n'est pas encore disponible. Elle sortira d'abord sur Google Play, en test interne, puis pour tous. La version iPhone viendra ensuite.

Pour savoir quand elle sort, suivez l'issue de publication sur Google Play sur GitHub.

Construire un premier pack

Aujourd'hui, un pack se construit sur un ordinateur, avec la ligne de commande du projet. Vous le regardez ensuite dans le visualiseur, dans votre navigateur. Les images de ce site viennent de là.

Ce qu'il faut

  • Un ordinateur sous Linux. Le projet y est développé et testé.
  • git et rustup. Le dépôt fixe la version de Rust dans rust-toolchain.toml ; rustup toolchain install, lancé dans le dépôt, l'installe.
  • Une connexion à internet pour le premier passage, et quelques gigaoctets de disque. Le cache des sources occupe 5 Go pour les deux sites tests.
  • Facultatif : une clé de l'API de Météo-France, pour le bulletin d'avalanche du jour. Sans clé, la chaîne de données lit l'archive publique des bulletins.

1. Récupérer le code

git clone https://github.com/traceblanche/traceblanche
cd traceblanche
cargo run --release -p skimap-cli -- sites

La dernière commande compile la ligne de commande, puis liste les sites connus :

cervieres          Cervières (05, INSEE 05027)
  massif Météo-France   : 17 Queyras (vérifié sur les polygones snowtools) ; BERA : oui
chapelle-des-bois  Chapelle-des-Bois (25, INSEE 25121)
  massif Météo-France   : 55 Haut-Doubs / 56 Haut-Jura (vérifié sur les polygones snowtools) ; BERA : non

2. Construire le pack

cargo run --release -p skimap-cli -- build-all cervieres

La commande télécharge les sources, calcule chaque couche dans l'ordre de leurs dépendances, puis écrit le pack dans data/out/cervieres/pack/. Elle affiche une ligne par étape, avec son temps et ses chiffres clés :

Le premier passage télécharge les sources : relief LiDAR HD, tuiles du Plan IGN, extrait d'OpenStreetMap, simulation de neige, cartes de l'ARCEP. Avec le cache déjà rempli, la construction prend quelques minutes, dont l'essentiel pour l'exposition aux avalanches. Le pack de Cervières pèse alors 39,6 Mo ; celui de Chapelle-des-Bois, 35,0 Mo.

Les sources réservées à un usage personnel restent désactivées par défaut : elles n'entrent jamais dans un pack publié. Leurs étapes sont alors sautées.

3. Regarder le pack

cargo run --release -p skimap-cli -- serve

Ouvrez ensuite http://127.0.0.1:8765/tools/viewer/index.html?pack=../../data/out/cervieres/pack/ dans votre navigateur. Le panneau du visualiseur choisit le style de carte (ski de fond, hors piste, guidage) et les couches ; toucher un objet ouvre sa fiche. Le visualiseur charge MapLibre et PMTiles depuis jsDelivr au premier affichage, puis toutes les données viennent du pack, sur votre machine.

4. Calculer un itinéraire

cargo run --release -p skimap-cli -- route cervieres \
  44.85894,6.725006 44.84465,6.8157 --date 2027-01-15 --start 13:00

temps estimé (C5) : 2h15 (montée 1h48, plat 0h22, descente 0h05), 5.1 km/h de moyenne

L'itinéraire est écrit en GeoJSON dans route.geojson. Les autres commandes sont décrites dans docs/architecture/compiler.md.

Contribuer au code

Le dépôt est un espace de travail Rust : une crate par domaine (pistes, relief, neige, zones, refuges, réseau, avalanches, pack, noyau, voix) et une ligne de commande qui les relie. docs/architecture.md en donne la carte. L'app Android en Kotlin viendra s'y ajouter.

  1. Choisissez une issue, ou ouvrez-en une pour décrire votre changement avant d'y passer du temps.
  2. Écrivez le test qui prouve le changement. Si une sortie de référence bouge, mettez-la à jour dans le même commit et expliquez l'écart.
  3. Lancez les vérifications : 
    cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
  4. Signez chaque commit avec git commit -s, selon le Developer Certificate of Origin.
  5. Ouvrez la demande de fusion. Collez les sorties des commandes et cochez la phrase d'accord sur la licence et l'exception pour les boutiques d'applications.

Les contributions écrites avec un outil d'IA sont bienvenues : vous les relisez, vous apportez les preuves et vous en répondez comme de votre propre code.
